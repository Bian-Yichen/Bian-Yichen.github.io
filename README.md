# Yichen Bian — Academic Homepage

Personal academic homepage served at <https://bian-yichen.github.io/>.

## Edit locally

```bash
git clone https://github.com/Bian-Yichen/Bian-Yichen.github.io.git
cd Bian-Yichen.github.io
```

- Edit profile text, news, publications, and links in `index.html`.
- Edit colors, spacing, typography, and responsive layout in `styles.css`.
- Replace the portrait and publication images in `assets/`. Keep the existing
  filenames if you do not want to update the paths in `index.html`.

Preview the site locally with:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>. To publish changes, commit and push to the
`main` branch; GitHub Pages will deploy the updated site automatically.
